cat statement_of_purpose.txt

ผม นายอาลีฟ เกษมสวัสดิ์ ชื่นชอบในด้านคอมพิวเตอร์มาตั้งแต่ยังเด็กและมีงานอดิเรกส่วนใหญ่คือเล่นเกม ความสนใจดังกล่าวไม่ได้เกิดจากแค่เพียงใช้งานคอมพิวเตอร์หรือแค่เล่นเกมธรรมดา แต่เริ่มเกิดจากการสงสัยว่าคอมพิวเตอร์นั้นทำงานได้ไง?

จุดเริ่มต้นสำคัญเกิดขึ้นเมื่อผมมีโอกาสประกอบคอมพิวเตอร์ครั้งแรกด้วยตนเองจึงเกิดความสนใจใน Hardware จากที่ได้ศึกษาทดลองปฏิบัติ ทำให้ผมได้สืบค้นความรู้ด้าน Software อีกด้วย โดยเฉพาะการเขียนโค้ดที่ทำให้ผมสนใจการสร้างเกม ซึ่งการสนใจด้าน Hardware และ Software จะเป็นจุดเริ่มต้นสำคัญที่ผมจะสนใจในด้านวิศวกรรมในอนาคต เนื่องด้วยผมศึกษาความรู้เกี่ยวกับการพัฒนาเกมมากขึ้น ผมจึงตั้งคำถามว่า “หากเกมที่เราเล่นอยู่ทุกวัน เราเป็นผู้สร้างขึ้นเองจะเป็นอย่างไร”

คำถามนี้ได้กลายเป็นแรงบันดาลใจที่ผลักดันให้ผมเริ่มสร้างเกมจากแพลตฟอร์ม Roblox ก่อนจะต่อยอดสู่การสร้างเกมบน Unity โดยตลอดการสร้างเกมผมก็ได้ศึกษาการเขียนโค้ดอย่างจริงจัง และลงมือสร้างเกมตั้งแต่การ Design, Coding, Testing, การแก้ไข Bug ต่างๆ, Publish และการทำโปรโมทด้วยตนเองบนแพลตฟอร์มต่างๆเช่น Tiktok และ Youtube เป็นต้น จนสามารถสร้างฐานผู้เล่นให้กับเกมที่ผมตั้งใจสร้างขึ้นและยังพบกับปัญหาต่างๆที่จำเป็นต้องแก้ไข

ประสบการณ์ดังกล่าวทำให้ผมเรียนรู้ว่าการพัฒนาเกมที่ดีไม่ได้อาศัยความสามารถในการเขียนโค้ดอย่างเดียวแต่ต้องอาศัยการคิดวิเคราะห์แบบ Logical Thinking ที่สามารถแบ่งหน้าที่ความสำคัญในส่วนต่างๆเป็นลำดับได้อย่างละเอียด ต่อมาผมยังศึกษาความรู้เพิ่มเติมเกี่ยวกับภาษาโปรแกรม เช่น Python, C, C++, Lua, JavaScript, HTML, CSS และ TypeScript รวมทั้งศึกษาเกี่ยวกับเครื่องมือต่างๆอย่าง Git และลึกลงไปถึงหลักการประมวลผลของคอมพิวเตอร์อย่าง Binary Code, โครงสร้างการทำงานของคอมพิวเตอร์ และ องค์ประกอบของ Hardware กับ Software ทั้งหมดนี้เพื่อเข้าใจในรากฐานของคอมพิวเตอร์อย่างลึกซึ้ง

ทั้งนี้ผมเห็นว่าวิศวกรรมคอมพิวเตอร์นั้นตรงตามความชอบในคอมพิวเตอร์อย่างมาก นอกจากนี้ผมยังมีประสบการณ์สร้างสื่อวิดีโอในแพลตฟอร์ม YouTube เป็นเวลามากกว่าหลายปีทำให้ผมมีทักษะและความรู้ในการตัดต่อ, การทำกราฟฟิค, เทคนิคการทำโปรโมท และ การพูดบรรยายอย่างมืออาชีพ ซึ่งความรู้และประสบการณ์เหล่านี้ช่วยพัฒนาทักษะด้านความคิดสร้างสรรค์, การสื่อสาร และ การทำงานอย่างเป็นระบบ สามารถสื่อได้ว่าผมมีการ Self Learning อยู่ตลอดเวลา

ด้วยประสบการณ์ทั้งหมดกับสิ่งที่ผมชื่นชอบไม่ใช่แค่คอมพิวเตอร์แต่เป็น แนวคิดเชิงวิศวกรรม ที่ให้ความสำคัญกับ การตั้งคำถาม, การค้นหาความจริงผ่านการลงมือทำ, การใช้ความรู้รองรับแนวคิดและพิสูจน์ผลลัพธ์อย่างเป็นระบบ ซึ่งผมยึดถือหลักการดังกล่าวในการเรียนรู้และพัฒนาตนเองกับการมุ่งมั่นด้านคอมพิวเตอร์มาตลอดพร้อมทั้งเป็นจุดเริ่มต้นให้ผมมีโอกาสเข้าร่วมการแข่งขันด้านโครงงานวิทยาศาสตร์ที่จัดขึ้นในมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรีซึ่งผมทำโครงงานที่มีชื่อว่า“ทุ่นลอยน้ำสร้างกระแสไฟฟ้า”หลักการทำงานคือลูกตุ้มข้างในทุ่นจะแกว่งไปชนเพียโซอิเล็กทิกส์ที่สร้างกระแสไฟฟ้าเมื่อถูกกระแทกจากลูกตุ้มทำงานร่วมกับอุปกรณ์ IoT และ นำแนวคิดเชิงวิศวกรรมมาประยุกต์ใช้และได้ผลลัพธ์ตรงตามเป้าหมาย

ผมได้เรียนรู้ทักษะต่างๆเช่น การแก้ไขปัญหา, การนำเสนอแบบมืออาชีพ, การวางแผนการทำงานกันเป็นทีมที่แบ่งหน้าที่อย่างชัดเจนซึ่งผมรับผิดชอบในการประดิษฐ์ที่จำเป็นต้องเขียนโค้ด และ ความรู้ใหม่ๆที่ได้จากอาจารย์หรือเพื่อนทีมอื่นอย่างเห็นได้ชัดคือ จุดเด่นจุดด้อยที่ควรปรับปรุงพัฒนา, ความคิดเห็นที่มีประโยชน์จากอาจารย์ ซึ่งผมตั้งใจรับฟังข้อเสนอแนะและคำติชมต่างๆพร้อมนำกลับมาพัฒนาผลงานในปัจจุบันกับอนาคตอย่างดีที่สุด

ผมตั้งเป้าหมายจะเข้าศึกษาต่อที่มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี คณะวิศวกรรมศาสตร์ สาขาวิศวกรรมคอมพิวเตอร์ เนื่องจากความพร้อมด้านเทคโนโลยีและหลักสูตรในแต่ละปีมีความเข้มข้นและทันสมัยทั้ง การปูพื้นฐานสร้างความเข้าใจในวิศวกรรม, การปฏิบัติจริง, การทำโครงงานหรือนวัตกรรม และ การแก้ไขปัญหาที่เกิดขึ้น

นอกเหนือจากหลักสูตรการสอนสภาพแวดล้อมที่นี่ยังสำคัญอย่างมากเช่น สังคมภายในมหาวิทยาลัยที่เป็นมิตรและมุ่งเน้นการศึกษาพร้อมแลกเปลี่ยนความรู้, สถานที่ตั้งมีธรรมชาติและบรรยากาศที่เหมาะสมกับสถานศึกษา และ อาคารต่างๆที่ไม่ไกลจากกัน ผมยังได้สัมผัสบรรยากาศภายในมหาวิทยาลัยอย่างใกล้ชิดจากกิจกรรมต่างๆที่ได้เข้าร่วมเช่น Open House และ การแข่งขัน เป็นต้น ผมยิ่งมั่นใจว่ามหาวิทยาลัยแห่งนี้มีการเรียนรู้ที่เข้มข้นในด้านวิศวกรรมพร้อมส่งเสริมและสร้างศักยภาพได้อย่างมีประสิทธิภาพและเชื่อว่ามหาวิทยาลัยสามารถสร้างผู้เรียนที่ทำประโยชน์ตามความต้องการในสังคมด้วยความรู้ทั้งหมดที่ได้มาจากมหาวิทยาลัยและได้ทำงานตรงสายที่ตั้งไว้อย่างแน่นอน

ผมสนใจในสายงาน ที่เกี่ยวข้องกับคอมพิวเตอร์เช่น Full-Stack Developer, Software Engineer และ Cyber Security เป็นต้น รวมทั้งยังชื่นชอบในปัญญาประดิษฐ์(AI)ทั้งแบบที่เป็น Generative ธรรมดา, AI Agent และ ระดับอุตสาหกรรมใหญ่ ซึ่งผมเชื่อว่าพื้นฐานความรู้และทักษะต่างๆจากมหาวิทยาลัยนั้นจะสามารถนำไปต่อยอดในสายงานดังกล่าวได้อย่างมีประสิทธิภาพสูงสุด

สิ่งที่สำคัญคือ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรีคณะวิศวกรรมศาสตร์สาขาวิศวกรรมคอมพิวเตอร์สามารถพัฒนาให้สามารถไปถึงสายงานดังกล่าวได้ทั้งหมดเนื่องจากปัจจัยสำคัญคือทางมหาวิทยาลัยนั้นมีศักยภาพที่จะส่งข้าพเจ้าไปทำงานสายงานดังกล่าวได้อย่างมีทักษะความรู้กับการทำงานเป็นทีมภายใต้แรงกดดันอย่างมืออาชีพ

Statement of Purpose

ผม นายอาลีฟ เกษมสวัสดิ์ ชื่นชอบในด้านคอมพิวเตอร์มาตั้งแต่ยังเด็กและมีงานอดิเรกส่วนใหญ่คือเล่นเกม ความสนใจดังกล่าวไม่ได้เกิดจากแค่เพียงใช้งานคอมพิวเตอร์หรือแค่เล่นเกมธรรมดา แต่เริ่มเกิดจากการสงสัยว่าคอมพิวเตอร์นั้นทำงานได้ไง?

จุดเริ่มต้นสำคัญเกิดขึ้นเมื่อผมมีโอกาสประกอบคอมพิวเตอร์ครั้งแรกด้วยตนเองจึงเกิดความสนใจใน Hardware จากที่ได้ศึกษาทดลองปฏิบัติ ทำให้ผมได้สืบค้นความรู้ด้าน Software อีกด้วย โดยเฉพาะการเขียนโค้ดที่ทำให้ผมสนใจการสร้างเกม ซึ่งการสนใจด้าน Hardware และ Software จะเป็นจุดเริ่มต้นสำคัญที่ผมจะสนใจในด้านวิศวกรรมในอนาคต เนื่องด้วยผมศึกษาความรู้เกี่ยวกับการพัฒนาเกมมากขึ้น ผมจึงตั้งคำถามว่า “หากเกมที่เราเล่นอยู่ทุกวัน เราเป็นผู้สร้างขึ้นเองจะเป็นอย่างไร” คำถามนี้ได้กลายเป็นแรงบันดาลใจที่ผลักดันให้ผมเริ่มสร้างเกมจากแพลตฟอร์ม Roblox ก่อนจะต่อยอดสู่การสร้างเกมบน Unity โดยตลอดการสร้างเกมผมก็ได้ศึกษาการเขียนโค้ดอย่างจริงจัง และลงมือสร้างเกมตั้งแต่การ Design, Coding, Testing, การแก้ไข Bug ต่างๆ, Publish และการทำโปรโมทด้วยตนเองบนแพลตฟอร์มต่างๆเช่น Tiktok และ Youtube เป็นต้น จนสามารถสร้างฐานผู้เล่นให้กับเกมที่ผมตั้งใจสร้างขึ้นและยังพบกับปัญหาต่างๆที่จำเป็นต้องแก้ไขหลายอย่าง ประสบการณ์ดังกล่าวทำให้ผมเรียนรู้ว่าการพัฒนาเกมที่ดีไม่ได้อาศัยความสามารถในการเขียนโค้ดอย่างเดียวแต่ต้องอาศัยการคิดวิเคราะห์แบบ Logical Thinking ที่สามารถแบ่งหน้าที่ความสำคัญในส่วนต่างๆเป็นลำดับได้อย่างละเอียด ต่อมาผมยังศึกษาความรู้เพิ่มเติมเกี่ยวกับภาษาโปรแกรม เช่น Python, C, C++, Lua, JavaScript, HTML, CSS และ TypeScript รวมทั้งศึกษาเกี่ยวกับเครื่องมือต่างๆอย่าง Git และลึกลงไปถึงหลักการประมวลผลของคอมพิวเตอร์อย่าง Binary Code, โครงสร้างการทำงานของคอมพิวเตอร์ และ องค์ประกอบของ Hardware กับ Software ทั้งหมดนี้เพื่อเข้าใจในรากฐานของคอมพิวเตอร์อย่างลึกซึ้ง ทั้งนี้ผมเห็นว่าวิศวกรรมคอมพิวเตอร์นั้นตรงตามความชอบในคอมพิวเตอร์อย่างมาก นอกจากนี้ผมยังมีประสบการณ์สร้างสื่อวิดีโอในแพลตฟอร์ม YouTube เป็นเวลามากกว่าหลายปีทำให้ผมมีทักษะและความรู้ในการตัดต่อ, การทำกราฟฟิค, เทคนิคการทำโปรโมท และ การพูดบรรยายอย่างมืออาชีพ ซึ่งความรู้และประสบการณ์เหล่านี้ช่วยพัฒนาทักษะด้านความคิดสร้างสรรค์, การสื่อสาร และ การทำงานอย่างเป็นระบบ สามารถสื่อได้ว่าผมมีการ Self Learning อยู่ตลอดเวลา

ด้วยประสบการณ์ทั้งหมดกับสิ่งที่ผมชื่นชอบไม่ใช่แค่คอมพิวเตอร์แต่เป็น แนวคิดเชิงวิศวกรรม ที่ให้ความสำคัญกับ การตั้งคำถาม, การค้นหาความจริงผ่านการลงมือทำ, การใช้ความรู้รองรับแนวคิดและพิสูจน์ผลลัพธ์อย่างเป็นระบบ ซึ่งผมยึดถือหลักการดังกล่าวในการเรียนรู้และพัฒนาตนเองกับการมุ่งมั่นด้านคอมพิวเตอร์มาตลอดพร้อมทั้งเป็นจุดเริ่มต้นให้ผมมีโอกาสเข้าร่วมการแข่งขันด้านโครงงานวิทยาศาสตร์ที่จัดขึ้นในมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรีซึ่งผมทำโครงงานที่มีชื่อว่า“ทุ่นลอยน้ำสร้างกระแสไฟฟ้า”หลักการทำงานคือลูกตุ้มข้างในทุ่นจะแกว่งไปชนเพียโซอิเล็กทิกส์ที่สร้างกระแสไฟฟ้าเมื่อถูกกระแทกจากลูกตุ้มทำงานร่วมกับอุปกรณ์ IoT และ นำแนวคิดเชิงวิศวกรรมมาประยุกต์ใช้และได้ผลลัพธ์ตรงตามเป้าหมาย ผมได้เรียนรู้ทักษะต่างๆเช่น การแก้ไขปัญหา, การนำเสนอแบบมืออาชีพ, การวางแผนการทำงานกันเป็นทีมที่แบ่งหน้าที่อย่างชัดเจนซึ่งผมรับผิดชอบในการประดิษฐ์ที่จำเป็นต้องเขียนโค้ด และ ความรู้ใหม่ๆที่ได้จากอาจารย์หรือเพื่อนทีมอื่นอย่างเห็นได้ชัดคือ จุดเด่นจุดด้อยที่ควรปรับปรุงพัฒนา, ความคิดเห็นที่มีประโยชน์จากอาจารย์ ซึ่งผมตั้งใจรับฟังข้อเสนอแนะและคำติชมต่างๆพร้อมนำกลับมาพัฒนาผลงานในปัจจุบันกับอนาคตอย่างดีที่สุด

ผมตั้งเป้าหมายจะเข้าศึกษาต่อที่มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี คณะวิศวกรรมศาสตร์ สาขาวิศวกรรมคอมพิวเตอร์ เนื่องจากความพร้อมด้านเทคโนโลยีและหลักสูตรในแต่ละปีมีความเข้มข้นและทันสมัยทั้ง การปูพื้นฐานสร้างความเข้าใจในวิศวกรรม, การปฏิบัติจริง, การทำโครงงานหรือนวัตกรรม และ การแก้ไขปัญหาที่เกิดขึ้น นอกเหนือจากหลักสูตรการสอนสภาพแวดล้อมที่นี่ยังสำคัญอย่างมากเช่น สังคมภายในมหาวิทยาลัยที่เป็นมิตรและมุ่งเน้นการศึกษาพร้อมแลกเปลี่ยนความรู้, สถานที่ตั้งมีธรรมชาติและบรรยากาศที่เหมาะสมกับสถานศึกษา และ อาคารต่างๆที่ไม่ไกลจากกัน ผมยังได้สัมผัสบรรยากาศภายในมหาวิทยาลัยอย่างใกล้ชิดจากกิจกรรมต่างๆที่ได้เข้าร่วมเช่น Open House และ การแข่งขัน เป็นต้น ผมยิ่งมั่นใจว่ามหาวิทยาลัยแห่งนี้มีการเรียนรู้ที่เข้มข้นในด้านวิศวกรรมพร้อมส่งเสริมและสร้างศักยภาพได้อย่างมีประสิทธิภาพและเชื่อว่ามหาวิทยาลัยสามารถสร้างผู้เรียนที่ทำประโยชน์ตามความต้องการในสังคมด้วยความรู้ทั้งหมดที่ได้มาจากมหาวิทยาลัยและได้ทำงานตรงสายที่ตั้งไว้อย่างแน่นอน

ผมสนใจในสายงาน ที่เกี่ยวข้องกับคอมพิวเตอร์เช่น Full-Stack Developer, Software Engineer และ Cyber Security เป็นต้น รวมทั้งยังชื่นชอบในปัญญาประดิษฐ์(AI)ทั้งแบบที่เป็น Generative ธรรมดา, AI Agent และ ระดับอุตสาหกรรมใหญ่ ซึ่งผมเชื่อว่าพื้นฐานความรู้และทักษะต่างๆจากมหาวิทยาลัยนั้นจะสามารถนำไปต่อยอดในสายงานดังกล่าวได้อย่างมีประสิทธิภาพสูงสุด

สิ่งที่สำคัญคือ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรีคณะวิศวกรรมศาสตร์สาขาวิศวกรรมคอมพิวเตอร์สามารถพัฒนาให้สามารถไปถึงสายงานดังกล่าวได้ทั้งหมดเนื่องจากปัจจัยสำคัญคือทางมหาวิทยาลัยนั้นมีศักยภาพที่จะส่งข้าพเจ้าไปทำงานสายงานดังกล่าวได้อย่างมีทักษะความรู้กับการทำงานเป็นทีมภายใต้แรงกดดันอย่างมืออาชีพ
